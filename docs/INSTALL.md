# GT-AX6000：USB 完整版安装

版本 **0.3.1**，适配目标 GT-AX6000 / ARM64、3004.388.4、ASUS GO / Koolshare 软件中心 1.9.57。包含官方 mihomo **v1.19.33**。当前版本已完成本地构建和隔离验证，路由器安装验收待完成。

如果 0.2.0 报告“/jffs 的实际设备未识别为 USB 存储”，直接上传 0.3.1 USB 完整包重试，不需要重新格式化。该包保留 0.2.1 增加的旧式 sysfs 整盘 device 链接及备用块设备入口识别；继续校验实际设备编号、EXT4、可写状态和目录归属。失败时输出具体设备与检测路径，便于定位。0.2.0 此处退出发生在修改现有安装之前。

## 只使用这一份安装包

`cwclash_hnd_v8_usb_0.3.1.tar.gz`，约 25.4 MB；解包持久文件约 58.5 MiB，安装后至少保留 128 MiB。无需先装 bootstrap，也无需为了放下本插件清理 ASD 检查备份。

源码包 `cwclash-source-0.3.1.tar.gz` 和 `mihomo-v1.19.33-corresponding-source.tar.gz` 用于保存和审查，不要上传到软件中心。可使用相邻 `.sha256` 或 `SHA256SUMS` 校验安装文件。

## 新 U 盘到后

1. 核对 U 盘的型号、容量和设备编号，再将指定分区格式化为 EXT4。格式化会删除所选目标的数据，先明确目标设备，并使用读写正常的 U 盘。
2. 将新盘接到路由器，使用软件中心的官方 **USB2JFFS** 完成挂载。仅在路由器看到一个普通 USB 分区还不够：USB2JFFS 必须把它挂载到 **`/jffs`**，软件中心目录也应位于该盘。首次迁移和复制需要等待完成。
3. 确认 USB2JFFS 报告成功、软件中心可打开，再进行长城 Clash 安装。官方实现及启动/停止钩子见 [USB2JFFS 源码](https://github.com/koolshare/rogsoft/tree/master/usb2jffs/usb2jffs)。
4. 软件中心 → 离线安装，上传 `cwclash_hnd_v8_usb_0.3.1.tar.gz`，无需解压。安装器先校验全部文件、在内存执行管理程序版本检查，再核对 USB 挂载、目标目录和剩余空间；失败原因写入安装日志。
5. 日志出现“已安装到 USB 持久存储”及软件中心安装成功后，打开“长城 Clash”。0.3.1 保留固件顶部和左侧菜单，插件内使用横向功能标签，自动跟随软件中心皮肤。旧页面可按 Ctrl+F5 刷新。设置中的 USB 存储信息应显示 EXT4、目录和可用容量。
6. 导入自己的 Clash/mihomo YAML 文件或订阅，检查内核版本，再启用代理。测试默认不使用私人订阅；透明代理与 IPv6 实机验证在新盘接入后完成。

安装器不仅检查文件系统名称，还通过 Linux 挂载编号、块设备及 sysfs USB 拓扑核对实际目标；内置闪存、只读分区或落在其他设备上的目录会被拒绝。

## 文件位置与启动

| 内容 | 位置 |
| --- | --- |
| 配置、订阅、线路选择、内核和资源 | USB 上的 `/koolshare/cwclash` |
| HTTP provider、GeoIP 与 Fake-IP 等运行缓存 | USB 上的 `/koolshare/cwclash/data` |
| 已校验运行程序、PID、令牌、接管规则记录 | 内存 `/tmp/cwclash-run` |
| 页面、脚本和开关机钩子 | USB 上的软件中心目录 |

持久内核保存官方原始文件，启动按块校验并复制到内存，不再进行 XZ 解压。管理程序仍使用小型 tar.gz 保存。执行程序放在内存也让独立清理任务在挂载丢失时能够运行；检测到挂载改变会撤销本插件接管。真实 USB 故障可能造成内核 I/O 卡顿，尚不能据本地模拟承诺拔盘恢复时限。

固件启动先运行 USB2JFFS 的 `S02`，再运行本插件的 `S98`。软件中心停止脚本按名称倒序调用 `T*`，本插件的 `T98` 在 USB2JFFS 的 `T50` 卸载前停止。NAT 更新通过 `N98` 调用本插件自己的规则恢复。钩子显式传入操作参数，兼容固件无参数执行方式。

## 更新、回退与卸载

直接在软件中心覆盖安装 USB 完整包，已有配置保留。内核更新写入 U 盘候选文件，摘要和版本验证通过后再切换，并保留一个上一版本供回退；空间不足或文件损坏时拒绝替换。若已经使用不同版本的内核，重装不会仅因附带旧版本而强制降级。

USB 规则缓存跨运行目录和重启保留，减少重复下载；实际缓存能否离线使用仍受上游配置和 mihomo 自身刷新策略影响。插件导出备份不是整盘镜像，完整固件/JFFS 备份应另行保留。

关机、重启或移除 U 盘前先停止代理。软件中心卸载会移除服务和页面，保留订阅、配置及内核；如需彻底删除私人数据，先导出备份再处理。不需要删除软件中心数据库或关闭 ASD。
