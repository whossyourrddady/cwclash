# 连通检查、流媒体与仅测速模式（0.3.9）

## 一眼查看网络

概览顶部展示三个独立判断：

- **内网 LAN**：配置的网桥是否启用、有可用 IP 地址；当前浏览器到管理服务是否可达。网桥状态不能代表每一个 LAN 插孔或 Wi-Fi 终端。
- **外网 WAN 接口**：读取 ASUS 主 WAN 单元的接口、IP 和可用时的 carrier 状态。PPPoE 等区分逻辑接口与底层网卡。固件不提供信息时显示未知，不按猜测亮绿灯。
- **外网直连**：由路由器直接 HTTPS 请求百度、阿里云；任一成功代表参考地址可访问，不代表全球站点都可用。该请求不使用环境 HTTP 代理或本插件混合代理，但仍受系统路由、DNS 和其他网络软件影响。

网站卡片覆盖 GitHub、Google、ChatGPT、Claude、Gemini、YouTube、X、Telegram、Discord、Reddit、Wikipedia、Bing。运行 mihomo 时，经本机混合端口按当前配置模式/规则发送；内核未运行时直连。不同域名可能走不同节点，页面显示的 Cloudflare 出口 IP/地区只代表该域名的请求。

绿色代表本次 HTTPS 请求成功；401/403/429/451、服务器错误及未完成跳转为限制状态；DNS、证书、超时等连接错误独立说明。连通并不保证账号登录、ChatGPT/Claude 对话、视频播放或所有 LAN 设备透明代理正常。自定义代理认证导致 407 时明确报告本机代理认证要求，不能据此判定网站被封。

## 刷新与开销

进入概览可自动开始基础检测，约每 5 分钟刷新，可在卡片关闭自动检测。离开概览或隐藏浏览器后不再安排新轮次；已启动的一轮在后台完成。流媒体只手动检测。

每轮最多 4 个并发、单个 HTTP 请求最多 9 秒、整轮约 65 秒上限；同一管理服务只有一个检查任务，同类请求复用任务，完成 30 秒内复用结果。站点默认 HEAD，405/501 时回退 GET；媒体最多读取每页 512 KiB。不下载视频、不做带宽压测、不修改代理模式、防火墙或所选节点。

结果仅驻留内存，不写 U 盘。基础结果超过 10 分钟、流媒体超过 1 小时，或配置/策略/手动节点选择/内核进程改变后，标记待刷新。上游自动策略组可能在两次检测间自行换线，因此时间戳仍是结果的边界。此版未逐站分别强制测试 IPv4/IPv6。

## 流媒体地区与解锁线索

- Netflix：两个固定片目样本，读取明确的视频元数据与可识别的 requestCountry。存在视频元数据仅显示**疑似可用**；不存在时不推断“仅自制”或必然不可用。
- YouTube Premium：读取公开页面的订购入口和地区线索。订购入口只表示**疑似可用**，不表示用户有 Premium 权益。
- Disney+、Spotify、Prime Video、Max/HBO Max、Apple TV、Twitch：先检查页面连通，识别页面明确的地区限制；Spotify 可显示可识别的站点地区。缺少可靠信号时保持**解锁待验证**。
- 人机验证、403、页面变化、无法识别或读取不完整时，不报告已解锁。最终需用户自己的账号与实际内容播放验证。

公开页面线索参考 [RegionRestrictionCheck 源码](https://github.com/1-stream/RegionRestrictionCheck/blob/main/check.sh) 中 Netflix、YouTube Premium、Spotify 等检查思路；实现为独立 Go 检测器，未复制远程脚本、共享 cookie 或 Disney 令牌流程，也不下载/执行第三方脚本。检测规则依赖上游页面，可能失效；此时保留未知状态。

## 不接管流量也能测速

节点页点击「仅启动内核测速」。测速需要 mihomo 执行，但不必先把全家流量转给它：

- 启动前清理本插件残留接管，内核仅绑定 127.0.0.1。
- 禁用 REDIRECT/TPROXY、DNS 监听/转发、TUN、额外 listeners 与 tunnels，不调用网络接管计划。
- 可读取内核节点、测速、预选策略组、执行网站检查；选择记录跟随配置保存。
- 修改配置/设置、切模式、重启内核与内核更新仍保持仅测速模式。
- 点击「启用路由器代理」才重启为正式模式，并完成固件能力预检；失败会提示错误，不把测速成功当成透明代理已成功。
- 可停止测速内核；仅测速模式不设为开机自动启用，仍会占用 mihomo 的运行内存。

节点卡片中 select/Selector 组优先、默认展开；url-test/URLTest、fallback/Fallback、load-balance 等默认折叠，点击标题展开。折叠只改变展示，自动组继续由内核正常运行。GLOBAL 只在全局模式展示。

## 验证范围

Go 测试覆盖 HTTP/认证/限流错误、地区信号、未知/人机验证、重定向边界、并发上限、结果缓存/过期及测速模式监听配置。Windows 原生 mihomo 实测仅测速启动、真实节点延迟、选节点、模式切换、保存配置、重启、显式启用，以及原有保存失败保护。UI 使用真实安装包、模拟固件/接口、完全拦截外部请求，检查首页卡片、媒体状态、折叠卡片与测速启用流程。

这些验证没有访问用户路由器或私人订阅；GT-AX6000 真机安装、物理 WAN 状态、站点可达性与流媒体账号播放仍需在用户当前网络确认。
