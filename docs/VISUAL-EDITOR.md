# 节点与代理组可视化编辑（0.3.8）

入口：配置页每张配置卡的「编辑节点/组」，或节点页的「编辑当前配置节点/组」。停机时可编辑，不会为了显示编辑器启动代理。

## 操作流程

1. 选择节点或代理组，点击编辑；也可新增或复制。
2. 修改字段。组成员与代理集合通过勾选加入，↑/↓ 改变优先顺序。
3. 点击「应用到草稿」。这一操作只修改当前页面，尚未写入路由器。
4. 点击「校验并保存编辑」。通过 mihomo 检查后才保存；当前配置有内容变化且代理正在运行时，会短暂重启代理。

在线订阅默认「另存为本地配置副本」：副本不含订阅地址、不自动更新、不自动切换生效。保存后在配置页选择使用。取消该选项则直接修改原订阅文件，下次订阅更新可能覆盖这些修改。

## 字段与类型

节点类型入口与官方 mihomo v1.19.33 adapter/parser.go 对应：SS、SSR、SOCKS5、HTTP、VMess、VLESS、Snell、Trojan、Hysteria、Hysteria2、WireGuard、TUIC、ShadowQUIC、Gost Relay、DIRECT、DNS、REJECT、REMATCH、SSH、Mieru、AnyTLS、Sudoku、MASQUE、TrustTunnel、OpenVPN、Tailscale、ZeroTier、EasyTier。

常用协议显示服务器、端口及相应认证字段；提供 TLS、证书指纹、WebSocket、gRPC、Reality、插件和 dialer-proxy 等常用项。凭据默认隐藏，不存入浏览器 localStorage。复杂 peers、证书、协议专有字段可展开「高级 YAML（含凭据）」编辑当前项，点击「同步高级 YAML 到表单」后再应用到草稿。它不是完整配置输入框，也不是单节点分享链接解析器。

代理组提供 select、url-test、fallback、load-balance；可设置静态成员、代理集合与顺序、测速 URL/间隔/超时、筛选、容差、负载均衡策略、默认成员、空组后备和包含全部节点/集合。部分字段只适用于特定策略；最终由当前内核校验。已有项的类型锁定，换类型可复制或新增，避免残留旧协议专属字段。

## 保留、引用与冲突

- 使用 YAML 文档树更新修改字段，保留未修改字段与文档注释；不保证原文件字节排版完全相同。未展开的高级参数不会因表单未显示而被丢弃。
- 改名同步组成员、默认成员/后备、前置代理、集合下载代理、普通及逻辑规则目标、子规则目标。不会全文替换密码、服务器或任意字符串。
- 删除被引用项时指定替代目标；组成员去重并保留最前顺序。禁止循环引用、重复名称和无效端口。动态集合成员的最终有效性仍由内核确定。
- 插件设置中的分流目标、设备组、全局覆写等属于配置外引用。检测到相关名称时阻止直接改名/删除；需先新增替代目标、调整设置，再删除旧项。正则筛选等间接匹配需要自行核对。
- 编辑共享锚点或别名可能影响其他项，因此受影响项需先在 YAML 编辑器展开。原文件不会被静默展开或覆盖。
- 保存携带配置版本，后台订阅更新、其他页面改动或删除后会拒绝过期草稿。错误时编辑窗口保留，可以导出已应用草稿；未同步的高级 YAML / 未应用表单不会进入导出。
- 在线集合缓存里的节点不可直接改写；可编辑原始配置里的静态节点、组，以及对已有集合的引用。全局 YAML 覆写可能再次覆盖这里的修改，界面会提示。
